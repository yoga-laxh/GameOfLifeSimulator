# Cellular GPU : High Performance Game of  Life Simumator

**Real-time CPU & GPU-accelerated cellular automaa engin with interactive features.**

## Project Overview
---
This Project is designed to explore **Parallelism, data structure, and high-performance computation**. The initial CPU prototype demonstrates Conway's Game of Life with a console visualization. Later stages will integrate **GPU acceleration (CUDA)** and a Python dashboard for interactive rule tweaking.

---
## Features
- CPU-based simulation of Conway’s Game of Life
- Customizable grid size and number of generations
- Console visualization of live and dead cells
- Easy extension for GPU acceleration and dashboard integration
